# UI kit: risegame.com marketing site

Two click-through pages: **Home** and **Products** (use the header nav). Built from the
live copy on risegame.com (home + /products) and `docs/sources/design.md`. No site source
code or Figma file was supplied, so layout is a faithful *arrangement* of the real copy
in RiseGame's visual language, not a pixel trace of the WordPress theme.

Screens
- `HomePage.jsx`: dark hero, "RiseGame Gets It", five product tiles, testimonials on black, blog row, closing demo CTA.
- `ProductsPage.jsx`: Scheduler → Tryouts → Draft flow, then the locked product/job/access table.
- `Photo.jsx`: labeled photo placeholders. RiseGame photography is real youth-sports imagery; none shipped with the pack.

All copy is verbatim from the live site. Do not invent features or traction.
