# UI kit — Tryout Scheduler (signups.risegame.com)

Two surfaces, switchable at the top of `index.html`:

- `AdminSlots.jsx` — league-admin slot manager. Dark chrome bar, signup-open switch, spot counts, slot table with edit/delete, registered-players empty state, settings switches, delete confirmation dialog.
- `ParentSignup.jsx` — the four-step parent flow: division → time slot → player details → confirmation.

`data.js` holds the sample league, divisions and slots.

**Source caveat.** No Scheduler source code, Figma file or admin screenshots were supplied.
These screens are built from the product's locked job ("Parents sign up for tryout slots"),
its marketing copy, and the RiseGame visual foundations — treat the *styling* as ground truth
and the *information architecture* as a proposal to check against the live product.
