# Button

The one CTA control — one job per button, accent reserved for the single most important action on a view.

    <Button variant="primary" size="lg" iconRight="chevron-right">Request a Demo</Button>
    <Button variant="secondary">See Tutorials</Button>

Notes
- primary = #1DFE1B fill, black label; hover flips to #242424 + white. Only one primary per view.
- secondary / ghost take onDark on black chrome.
- Radius is 2px everywhere. No shadows or gradients on buttons.
- League-admin CTAs point at mailto:info@risegame.com or a product URL, not the App Store.
